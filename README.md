# 命理题库 · MingLi Bench 完整版

全球算命师大赛 2022–2025 年 160 道真题的在线版，单文件、零依赖、无后端。

包含四部分：

- **自测**：按年份/类别筛题、可选打乱选项、逐题即时判定、分类正确率、错题回顾
- **题库**：160 题全文检索、完整命盘（四柱、主辅星、庙旺、四化、杂曜、十二神、大限）、标准答案、赛题原文
- **榜单**：2025 年 40 题、5 轮多数票的完整成绩，含 Tianfu Agent 40 条逐题结果与推理链接
- **说明**：数据来源、指标口径、读榜提示

数据与标准答案来自 [MingLi-Bench](https://github.com/DestinyLinker/MingLi-Bench)（MIT License），原始赛题来自全球算命师大赛，命盘由 iztro 预先排定（未做真太阳时校正）。

部署：仓库根目录的 `index.html`，Settings → Pages → Deploy from a branch → `main` / `/ (root)`。
